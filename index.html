Memprogram Arduino dengan Bahasa Bali

Library yang mengkonversi bahasa pemrograman Arduino ke bahasa Bali. Membuat arduino lebih mudah sekaligus melestarikan bahasa daerah.

Mulai Belajar

Contoh Program



fungsi nyiapang() {
  mekawit(9600);  // Mulai komunikasi serial
}

fungsi abadi() {
  cetakln("Om Swastyastu!"); 
  antos(1000);               
}

Program sederhana untuk mencetak pesan ke Serial Monitor setiap 1 detik.

Mencari bilangan genap dan ganjil



angke counter = 0;  // Variabel counter

fungsi nyiapang() {
  mekawit(9600);
}

fungsi abadi() {
  counter = counter + 1;  // Tambah counter
  cetak("Counter: ");
  cetakln(counter);       // Cetak nilai counter
  
  yening (counter % 2 == 0) {
    cetakln("Genap");
  } liyanan {
    cetakln("Ganjil");
  }
  
  antos(500);  // Tunggu 0.5 detik
}

Program contoh menggunakan variabel dan operasi matematika.

Download Ardubali v1.0.0

Download library terbaru untuk mulai memprogram Arduino dengan bahasa Bali

Cara Install Library:

  1. Download file ZIP library Ardubali
  2. Buka Arduino IDE
  3. Pilih menu Sketch > Include Library > Add .ZIP Library
  4. Pilih file ZIP yang sudah didownload
  5. Library akan terinstall secara otomatis
  6. Restart Arduino IDE jika diperlukan
